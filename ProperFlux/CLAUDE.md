# ProperFlux Project Reference

## Overview
ProperFlux is the financial and Web3 powerhouse of the Proper AI Suite. It is a professional-grade trading dashboard, market tracker, and Token/NFT creation engine, powered by a Master Quantitative Trader & Web3 Architect Agent.

## Tech Stack
- **Frontend**: HTML5, Tailwind CSS (CDN), Vanilla JavaScript.
- **Styling**: Proper AI Suite Standard (Midnight Slate `#020617` / Neon Cyan `#00f3ff`).
- **Architecture**: Single Page Application (SPA) with a modular "Centered Rectangle" layout.

## UI Components & Styling
- **Theme**: Dark theme with glowing neon accents.
- **Layout**: "Centered Rectangle" Design:
    - **Header**: Center-aligned branding and high-impact description.
    - **Market Tracker**: A wide, centered glassmorphic rectangle showing real-time tickers, sentiment analysis, and trend heatmaps.
    - **Trading Dashboard**: A centered modular zone featuring portfolio overview, AI-driven trade signals, and risk management metrics.
    - **Asset Factory**: A dedicated section for Token and NFT creation, including tokenomics parameterization and rarity generation.
    - **Discovery Hub**: A curated grid of trending tokens and NFTs analyzed by the Master Agent.
- **Glassmorphism**: `.glass` for all containers.
- **Neon Elements**: `.neon-border`, `.neon-text`, and `.neon-button` for consistent suite branding.

## AI Agent: Master Quant & Web3 Architect
- **Expertise**: Top-tier mastery of algorithmic trading, on-chain analytics, and Tokenomics.
- **Core Capabilities**:
    - **Market Intelligence**: Real-time scanning of whales, liquidity pools, and social sentiment to predict price action.
    - **Token Architect**: Generates optimal tokenomics (supply, burn, tax) for new project launches.
    - **NFT Strategist**: Designs rarity matrices and utility frameworks for high-value NFT collections.
    - **Trade Signal Engine**: Provides professional-grade entry/exit points based on technical and fundamental analysis.

## Key Functions
- `handleLogin()`: Standard suite authorization and lead capture.
- `analyzeMarket()`: Triggers the Agent to scan the current market state and update tickers.
- `createToken()`: Orchestrates the parameters for creating a new Token/NFT.
- `getTradeSignal()`: AI-driven trade recommendation based on current volatility and trends.

## Project Structure
- `index.html`: All logic, styles, and HTML for the application.
